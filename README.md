## Shuting (Iris) Chen

Neuroscience PhD student at the University of Southern California with a computer science background. I build machine learning models that decode behavior and motor states from noisy biological time series.

**Research interests:** sequence modeling · multimodal machine learning · Bayesian state-space models · motor control and learning

---

### Selected projects

| Project | What it does |
|---|---|
| [mouse_activity_deep_learner](https://github.com/19990314/mouse_activity_deep_learner) | Frame-level behavior classifier for freely moving mice: DeepLabCut pose, MoSeq features and kinematics feed a dilated residual TCN (PyTorch), with Viterbi decoding and bout-level evaluation. |
| [Mouse-Forelimb-Muscleskeletal-Modeling](https://github.com/19990314/Mouse-Forelimb-Muscleskeletal-Modeling) | OpenSim musculoskeletal model of the mouse forelimb (6 DOF, 21 muscles) that quantifies muscle fascicle velocities during 3D reaching with Monte Carlo trajectory simulation; now being extended to design a mouse joystick task. |
| [rappid](https://github.com/19990314/rappid) | Laplacian-field pipeline for RaPPiD, a region-specific MRI metric of glymphatic function, run in parallel across a large cohort. |
| [Y-Maze-analyzer](https://github.com/19990314/Y-Maze-analyzer) | Python toolkit for annotating, labeling and statistically analyzing reward-based Y-maze videos. |
| [Running_Wheel_Activity_Analysis_GUI](https://github.com/19990314/Running_Wheel_Activity_Analysis_GUI) | GUI for running-wheel activity: wheel-running bout statistics, circadian actogram analysis, and a figure generator. |
| [Grid_Walking](https://github.com/19990314/Grid_Walking) · [balance_beam_analyzor](https://github.com/19990314/balance_beam_analyzor) | MATLAB pipelines for motor-coordination assays: calibration, tracking, speed and error metrics. |
